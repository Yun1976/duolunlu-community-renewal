# 过程笔记：视觉 IP 选定与探宝地图方法（2026-10-25）

> 去标识整理自川造社设计群 / 街道营造群知识页（2026-10-25）；公开方法论/过程叙述；不含个人身份与商户真名。

## 背景

2026-10-25 多条线索汇合：活动名称与视觉 IP 收敛、「探宝地图」定名，以及地图服务轻量识别的设计约束。同日对外进度口径：项目书初稿完成、参与商户排摸对接推进、已发动多位学生志愿者，细节仍在完善。

## 1. 活动命名

- 「风彩」释义讨论：风很大，兼有风尚、风貌、风情、风格。  
- 最终先行采用 **「风彩」**（「多彩」可接受但暂不采用）。  
- 曾出现替代提案如「多伦路—『多』彩文化季」（可涵盖整周期），未取代「风彩多伦」主品牌。

## 2. 视觉 IP 选定流程

多伦路系列活动需从候选方案中选定一个作为系列 IP。公开可述的方案类型包括：

1. **色块组合 / DUO·LUN 彩色几何字母**：字母重叠处混色，年轻化、饱和度高、半透明感——最终方向。  
2. 民国风字体版（左联 / 萌芽月刊气质，局部亮色）。  
3. 曲线版（多伦首字母母题，清新手绘放松质感）。  
4. 色块版（蒙德里安式抽象色块序列感）。  
5. 文字结合 logo（含「风彩多伦」「多伦路艺术季」及「多点看头，多点意思」等标语）。  
6. 其他备选（抽象线条、光晕字母等）。

**结论**：系列视觉 IP 方向定为方案 1（DUO / LUN 彩色几何字母标志，重叠混色，现代活泼），后续按此推进；整体视觉系统目标是提升多伦路品牌效应。

## 3. 探宝地图

- 正式名称定为 **「探宝地图」**（不用「探险地图」）。  
- 草稿形态：手绘底、道路勾线、色块标注打卡点，涂鸦风格；具体店名在公开库中一律泛化为「书店 / 文创点 / 老建筑打卡点 / 艺术中心」等角色。  
- 新增打卡点设想：「多伦路老朋友」旧书市集——形态为长条状，与点状打卡不同；选址描述保留到「两处文创/书店之间、马路同一侧 / 骑楼廊柱一带」的空间关系，不写商户真名。  
- **技术约束（方法亮点）**：若用地图做轻量视觉识别，地图**四角需做特殊视觉锚点**，便于模型定位；视觉设计阶段需与开发侧提前沟通。

## 4. 配色与主视觉落地

- 活动配色：从给定色板自由搭配。  
- 主视觉需提交管理方审定；可借用街区既有广告牌位并按实际尺寸设计（借用手续属内部流程，本库不展开）。

# 过程笔记：活动目标、漏斗路径与运营模式（2026-10-24）

> 去标识整理自川造社群聊知识页（2026-10-24）；公开方法论/过程叙述；不含个人身份与商户真名。

## 背景

2026-10-24 讨论密度高，核心是把「风彩多伦（第一期：摄影诗书季）」从概念落到可执行的目标、到店路径、平日/活动日运营分工，以及大学生伙伴参与的原则。金额、商户字号与个人指派一律不收录。

## 1. 两大活动目标（方法层）

1. 让商户发现更换经营模式与业态**有利可图**（用活动验证，而非口号）。  
2. 形成切入点，引导大学生**灵活就业 / 实践锻炼**（半公益定位：可教会职场技巧与专业能力）。

配套反思：未来项目书绩效宜纳入街区流量到店率、转化率与投入产出效率；三年治理与营造目标也应考虑效率，而不仅是活动场次。

## 2. 到店路径与打卡机制

- 项目书需写清**到店路径**：采用「进店探宝」玩法；每个参与商户需有可公开的说明与玩法介绍。  
- 盖章点可作为商户参与形式之一。  
- **平日轻量自助** + **活动日（周六）集中**：  
  - 平日：线上打卡拍照上传，奖励以数字化产品为主（如视觉作品线上入口）。  
  - 活动日：现场参与并兑奖，方可获得实物（明信片等）。  
- 原则：**线上打卡对应线上奖励，不与实物混用**。

## 3. 运营模式草案

- 活动日集中运营；平日自助领图、商户自助盖章、每周六下午集中兑换、特刊隔周更新。  
- 不另设全时段现场值守；若学生到岗不稳定，备选是把部分在地工作短期外包给合作文创点，或招募短期兼职（具体合作方与条款不公开）。

## 4. 大学生伙伴参与原则（去金额）

- 人员筛选：时间上模棱两可或明显推脱的，不承诺报酬；明确没有优先级的不安排。  
- 报酬沟通宜双向：考虑学术目的与作品集需求，而非单向「派工发钱」。  
- 已验证能力的伙伴可承担设计统筹、手绘地图 / IP / 印章、特刊、视频与沪语相关小设计等分工；未接触过的宜低承诺、按交付再定。  
- 建议与学生签订合作协议，保障经费使用有据可查；完成度过低可按协议处理。  
- 不采用「谈成赞助再抽成」的报酬模式。  
- 风险：周期内突击调研可完成，但要求每个周末固定到岗更难；中途以学业为由脱岗、交付不可预判，是主要风险。

## 5. 内容与传播方法

- 店铺采访视频风格：不追求精致剪辑，采用手持、直播感、轻微手抖；说清在哪里卖、卖什么、有什么特点。  
- 多平台试水：公开社交平台 + 小红书等；可由会英语的大学生伙伴做英语旁白采访，形成「多伦路店铺集合」类视频产品（肖像与商户授权另办，本库不收录素材）。

## 6. 「空间设计」在川造社语境下的含义

同日澄清：此处「空间设计」主要指**照片打印作品在物理空间中的陈列与呈现**（墙面悬挂、拼贴组合等），不是建筑装修外包的同义词。运营矩阵（内容板块 → 主视觉方向）需先定板块，再推视觉。

## 7. 政府项目审计的方法提醒（公开常识层）

- 外包给单位的支出，审计时通常需要发票；志愿者补贴常以签到单为支付依据。  
- 项目书所列经费支出宜有对应凭证；结项时常见做法是核对票据与项目书是否对齐。  
- 审计可能倒查多年——因此「先把账说清楚」比「先把 PPT 做漂亮」更关键。  
- 本库**不收录**任何具体金额、利润安排或内部科目拆分。

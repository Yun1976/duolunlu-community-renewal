## 背景

2026-10-23 团队围绕多伦路文化活动的品牌命名、视觉母题与季节系列结构展开讨论，并推进「方案 → 项目书」的流程。本笔记只保留可公开的方法与结论层。

## 1. 品牌命名

- 候选方向曾包括：「多伦风彩集」「风彩多伦」「多彩多伦」等。
- 命名逻辑参考公开文化产品常见的「印象 + 地名」系列结构（如印象系列山水实景演出的命名习惯），把「风彩」作为可延展的系列前缀。
- 群内倾向收敛到 **「风彩多伦」**。
- 「风」取风雅颂之风，兼有风尚 / 风貌 / 风情；「彩」取多彩之意。
- 标语试验采用「多点……」句式，例如摄影主题「多点看头」、诗歌主题「多点意思」；沪语向标语可归入「风」的范畴。

## 2. 季节系列与「三撇」结构

- 大活动按**季节系列**组织：每次大活动对应一个季节主题（如秋冬主打黄 / 金 / 棕色）。
- 每个季节下设**三个子主题**，对应视觉上的「三撇 / 彡」设计元素；当前秋冬三主题为：**摄影、诗歌、书画**。
- 「三撇」同时是视觉系统与活动结构的核心母题：三个子主题各占一撇。

## 3. Logo / 空间形态呼应（方法层）

- 多伦路道路平面近似 **L 形**；设计讨论中出现过「两个 L 拼合形成 X，寓意多彩、多样、多有趣」的变体思路。
- 另一条公开可述的设计母题：以「DL」（多 / 伦拼音首字母）为主要元素，并与街区 L 型空间形态形成字母—空间呼应。
- 多版不同风格方案可先产出，再在群内选定深化——**先出方案池，再收敛**，而非一次性定稿。

## 4. 在地维护与志愿者方法

- 商户通常一人守店，难以同时承担活动组织者角色；可行解法是派少量志愿者巡回关心查看，而不是要求商户额外值守。
- 志愿者招募以大学生为主，人数不求多；渠道可考虑公开志愿者平台或高校群。

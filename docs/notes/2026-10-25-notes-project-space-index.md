## 背景

本笔记把四川北路街道（多伦路 / 甜爱路街区）社区营造合作的**项目工作区组织方法**抽成可公开的索引说明，便于外部读者理解「一条街区营造项目的文档如何归拢、如何检索」，不展开未公开路径、服务器或经费细节。

维护者：张雪飞（云上雪）。知识真值另有内部库；本仓库只收录可公开层。

## 空间是什么（自我解释）

工作区只放**项目文档与成品**，按工作线分目录；不把线上系统源码、个人工作知识库、历史经验教训混在同一根目录。根目录原则上只保留「空间自述」一类入口文件，业务散件归入子目录——找任何东西先查目录地图。

- **摄影诗书季**：项目书版本链、实施方案、项目计划、大学生伙伴版、视觉与物料相关说明

## 品牌与版本链（可公开事实）

- 项目书品牌由「风**采**多伦」演进为「风**彩**多伦」，并升级为**艺术季系列**结构：
  - **风** = 风貌 / 风情 / 风尚
  - **彩** = 每期三个主题，对应「彡」笔形
  - **摄影诗书季** = 系列第一期
- 活动周期构想：秋冬档期内多个周六主题日（开幕 / 摄影 / 诗书 / 闭幕一类节奏）；具体报审以正式对外版本为准。
- 权威指向原则：每类文档只保留一个现行权威版；历史版本仅追溯，根目录不堆业务散件。

## 文档卫生（删除裁定原则）

2026-10-25 归拢时采用的公开可复用原则：

1. **不可归档**（临时渲染图、安装包、中间件）→ 删  
2. **不可检索但文本已在档**（例如超大录音，若已有全文转写 + 智能纪要）→ 可删原音  
3. **证实逐字节重复**（仅导出时间戳不同）→ 删旧留新  
4. **正式成品与全量孤本** → 留  

目标形态：根级散文件归零；空间自述成为唯一检索入口。

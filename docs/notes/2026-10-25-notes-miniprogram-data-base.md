# 过程笔记：小程序导览雏形与漏斗双动作（2026-10-25）

> 去标识整理自川造社小群知识页（2026-10-25）；公开方法论/过程叙述；不含个人身份与商户真名。

## 背景

在视觉与物料推进的同时，小群明确了「数据底座自己建」以及流程上两个必须完成的动作。本笔记只保留架构意图与流程约束。

## 1. 小程序 / 在线导览雏形

活动前拟搭建小程序，供日常自助游玩游客使用，功能设想包括：

- 到店探宝  
- 集章  
- 在线兑换折扣券  

定位：**多伦路在线导览雏形**，逐步积累生长为街区数据接口——而不是一次性大而全的平台。

## 2. 数据底座归属

- 若依赖某一在地文创合作方搭建数据系统，对方可能因无利可图而难以承诺；且对方系统未必提供到店率 / 兑换率，也未必能说服更多店铺入驻。  
- **决定：数据底座由项目方自行搭建。**  
- 合作方仍可提供少量免费点位支持活动（具体店名不公开）。

## 3. 流程上的两个必须动作

以下两项必须完成，并嵌入整个活动流程：

1. **多伦路商户对接与调研指引（大学生版）**——统一大学生伙伴怎么进店、问什么、如何记录。  
2. **漏斗计量机制设计**——把「到街 → 领图 → 到店 → 盖章 → 兑换 → 核销」变成可计量闭环（与项目空间索引中的漏斗线一致）。

## 4. 文档分层（方法提醒）

- 含费用信息的详细 Word / 明细版，不宜在扩大领导群直接公开；宜在执行小群内部分发。  
- 对外 / 对管理方可用去费用的 PPT 与主视觉稿；主视觉需提交审定。

# 过程笔记：设计流程、物料与志愿者标识（2026-10-25）

> 去标识整理自川造社 F4 / 伙伴群知识页（2026-10-25）；公开方法论/过程叙述；不含个人身份与商户真名。

## 背景

同日设计协作加密：单独建设计讨论群、梳理物料清单、明确志愿者标识形态，并处理项目方案中的命名与指标口径。金额与采购渠道细节不收录。

## 1. 设计协作方法

- 设计内容相互搭接（视觉 / 手绘地图 / 环境艺术 / 视频），宜**单独建群**跨方向协同。  
- 推进策略：**先确定视觉方向，再优化材质与细节**；流程上「先找案例，再选定方向」。  
- 整体风格定位：「活力且年轻人喜欢的」。  
- 外部设计社交笔记仅作风格参考索引，公开库不转载账号原名与未授权图。

## 2. 项目方案口径（公开层）

- 大学生伙伴版项目方案完成内部更新后发伙伴群讨论。  
- 参与商户**不写死具体家数**，避免人为限制与额外工作量。  
- 涉及历史名人书店名号时，统一使用不侵权的现行店招表述，避免误用纪念性专名。  
- 曝光量等绩效指标宜保守书写。  
- 商户对接与调研指引（大学生版）同日作为执行参考发布。

## 3. 游客动线观察

- 经验判断：一般游客从街区一端走到尽头后，不太可能折返另一端起点——打卡点与兑换点布局需尊重单向耗尽的动线习惯。

## 4. 物料与周边

- 物料大类：印刷物料、商户贴饰、定制开发等；宜做**按主题分类**的详细清单，并增加「时间节点」列，把各节点所需物料对齐。  
- 活动周边不宜设计过多：定制与生产周期长，可优先采购部分现成文创作为兑换礼，同时促进合作书店销售。  
- 带商铺名字且可替换的艺术化标识：倾向团队自行三维建模定制，而不是接受「纯艺术品、不能结合文字」的外包方案。

## 5. 志愿者标识与招募

- 标识形态采用**胸贴 / 肩贴**（非马甲），可设计内容，适量多备供后续活动复用；工作牌亦可作青年力等项目共用。  
- 四期周末活动需招募少量**固定岗位**志愿者；优先条件是四期稳定到岗；报名方式为自行报名或同学推荐；享有补助与保障（具体数额不公开）。

## 6. 线下打卡补充

- 日常线下打卡可与合作书店商谈：采购其现成文创作兑换礼，并请值守人员协助日常打卡沟通。  
- 打卡方式偏好**线下线上混合**（与 10-24 运营模式笔记一致）。
